# StudyBuddy — இரசாயனச் சமன்பாட்டுத் தேர்ச்சி

> **பொன் விதி: கீழ்க்குறிகளை (subscripts) ஒருபோதும் மாற்ற வேண்டாம் — குணகங்களை (coefficients) மட்டும் மாற்றுக.** கீழ்க்குறியை மாற்றினால் வேறு பதார்த்தம் ஆகிவிடும் (H₂O → H₂O₂).

## ஆறு படிச் சமன்செய்தல் முறை

1. சரியான சூத்திரங்களுடன் சொற் சமன்பாட்டை எழுதுக (வலுவளவுகளைப் பயன்படுத்தி).
2. ஒவ்வொரு பக்கத்திலும் ஒவ்வொரு மூலக அணுக்களையும் எண்ணுக.
3. ஒருமுறை மட்டும் தோன்றும் மூலகங்களை (பொதுவாக உலோகம்) முதலில் சமன்செய்க.
4. H ஐயும் இறுதியில் O ஐயும் சமன்செய்க; பல்லணு அயன்களை (SO₄ போன்றவை) ஒரே அலகாகக் கருதுக.
5. மீண்டும் எல்லா அணுக்களையும் எண்ணிச் சரிபார்க்க.
6. குணகங்களை மிகச்சிறிய முழு எண்களாக்கி நிலைக் குறியீடுகளைச் (s, l, g, aq) சேர்க்க.

> எல்லா சமன்பாடுகளும் Python அணு-எண்ணிக்கைப் பகுப்பாய்வியால் சரிபார்க்கப்பட்டன; குணகங்கள் மிகச்சிறிய முழு எண்கள் என்பதும் சரிபார்க்கப்பட்டது.

## பகுதி D — பிழையான சமன்செய்தலைத் திருத்துக

<!-- meta {"type":"eq_exercise","id":"EX-FIX-01","kind":"correct_balance","ref":"EQ-002"} -->
**EX-FIX-01.** மாணவர் எழுதியது: H₂ + O₂ → H₂O₂ — பிழை என்ன? திருத்துக.

<details><summary>விடை</summary>

சரியானது: **2H₂ + O₂ → 2H₂O**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-02","kind":"correct_balance","ref":"EQ-001"} -->
**EX-FIX-02.** மாணவர் எழுதியது: Mg + O₂ → MgO₂ — பிழை என்ன? திருத்துக.

<details><summary>விடை</summary>

சரியானது: **2Mg + O₂ → 2MgO**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-03","kind":"correct_balance","ref":"EQ-034"} -->
**EX-FIX-03.** மாணவர் எழுதியது: CH₄ + O₂ → CO₂ + 2H₂O — பிழை என்ன? திருத்துக.

<details><summary>விடை</summary>

இடப்பக்கம் O = 2, வலப்பக்கம் O = 4. O₂ க்கு 2 தேவை.

சரியானது: **CH₄ + 2O₂ → CO₂ + 2H₂O**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-04","kind":"correct_balance","ref":"EQ-013"} -->

<details><summary>விடை</summary>

இடப்பக்கம் H = 1, Cl = 1; வலப்பக்கம் 2. HCl க்கு 2 தேவை.

சரியானது: **Zn + 2HCl → ZnCl₂ + H₂**

| H₂ | எரியும் குச்சியை அருகே கொண்டுவர 'பொப்' ஒலியுடன் எரியும் |
| O₂ | தணல் குச்சி மீளப் பற்றி எரியும் |
| CO₂ | சுண்ணாம்பு நீரைப் பால் நிறமாக்கும் |
| NH₃ | ஈர நீலப் பாசிச்சாயத்தாளை நீலமாக்கும் (ஈரச் சிவப்புத் தாளை நீலமாக்கும்); HCl உடன் வெண் புகை |
| Cl₂ | ஈர நீலப் பாசிச்சாயத்தாளைச் சிவப்பாக்கிப் பின் வெளிறச் செய்யும் |
| SO₂ | அமிலமாக்கிய பொற்றாசியம் இருகுரோமேற்றைச் செம்மஞ்சளிலிருந்து பச்சையாக்கும் |

## வரையறைகள் (Limitations)

- 50 சமன்பாடுகள்; பயிற்சிகள்: 20 நிரப்புதல், 20 விடுபட்டது, 8 திருத்தல், 18 சூத்திர அமைப்பு, 6 வாயுச் சோதனை, 7 அரைச் சமன்பாடுகள்.
- துருப்பிடித்தல் சமன்பாடு (EQ-005) எளிமைப்படுத்தப்பட்டது; உண்மையில் நீரேற்றிய இரும்பு(III) ஒட்சைட்டு உருவாகும்.
- 'குணகம் உள்ளீடு செய்து உடனடிச் சரிபார்ப்பு' போன்ற ஊடாடும் வசதிகள் இணையத்தளத்தில் உருவாக்கப்பட வேண்டும் — meta JSON இல் எதிர்பார்க்கும் குணகங்கள் உள்ளன.

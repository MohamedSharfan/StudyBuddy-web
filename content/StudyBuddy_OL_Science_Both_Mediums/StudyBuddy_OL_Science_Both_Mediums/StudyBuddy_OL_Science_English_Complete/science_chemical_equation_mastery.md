# StudyBuddy — Chemical Equation Mastery

> **Golden rule: never change the subscripts — only change the coefficients.** Changing a subscript makes a different substance (H₂O → H₂O₂).

## Six-step balancing method

1. Write the word equation with correct formulae (using valencies).
2. Count the atoms of each element on each side.
3. Balance elements that appear only once (usually the metal) first.
4. Balance H and finally O; treat polyatomic ions (such as SO₄) as one unit.
5. Count all the atoms again to check.
6. Make the coefficients the smallest whole numbers and add state symbols (s, l, g, aq).

> All equations were checked by a Python atom-count analyser; it was also checked that the coefficients are the smallest whole numbers.

**EX-FIX-01.** A student wrote: H₂ + O₂ → H₂O₂ — what is wrong? Correct it.

<details><summary>Answer</summary>

The subscript was changed, turning H₂O into H₂O₂ — that is a different compound. Only the coefficients should be changed.

Correct: **2H₂ + O₂ → 2H₂O**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-02","kind":"correct_balance","ref":"EQ-001"} -->
**EX-FIX-02.** A student wrote: Mg + O₂ → MgO₂ — what is wrong? Correct it.

<details><summary>Answer</summary>

MgO₂ is a wrong formula (Mg²⁺, O²⁻ → MgO).

Correct: **2Mg + O₂ → 2MgO**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-03","kind":"correct_balance","ref":"EQ-034"} -->
**EX-FIX-03.** A student wrote: CH₄ + O₂ → CO₂ + 2H₂O — what is wrong? Correct it.

<details><summary>Answer</summary>

O = 2 on the left, O = 4 on the right. O₂ needs a 2.

Correct: **CH₄ + 2O₂ → CO₂ + 2H₂O**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-04","kind":"correct_balance","ref":"EQ-013"} -->
**EX-FIX-04.** A student wrote: Zn + HCl → ZnCl₂ + H₂ — what is wrong? Correct it.

<details><summary>Answer</summary>

H = 1, Cl = 1 on the left; 2 on the right. HCl needs a 2.

Correct: **Zn + 2HCl → ZnCl₂ + H₂**

</details>

<!-- meta {"type":"eq_exercise","id":"EX-FIX-05","kind":"correct_balance","ref":"EQ-035"} -->

**EX-FIX-07.** A student wrote: Fe + O₂ → Fe₂O₃ — what is wrong? Correct it.

<details><summary>Answer</summary>

Fe: 1 vs 2; O: 2 vs 3. 4Fe + 3O₂ → 2Fe₂O₃.

Correct: **4Fe + 3O₂ → 2Fe₂O₃**

</details>

**EX-FIX-08.** A student wrote: Fe₂O₃ + CO → 2Fe + CO₂ — what is wrong? Correct it.

<details><summary>Answer</summary>

O: 4 vs 2; C: 1 vs 1 — CO and CO₂ both need a 3.

Correct: **Fe₂O₃ + 3CO → 2Fe + 3CO₂**

</details>

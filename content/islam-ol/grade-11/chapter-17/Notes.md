# தரம் 11 – அத்தியாயம் 17: பிக்ஹுக் கலை

## 🎯 இந்த அத்தியாயத்தில் கற்பவை
- பிக்ஹ் என்றால் என்ன?
- பிக்ஹுக் கலையின் தோற்றமும் வளர்ச்சியும்
- நான்கு மத்ஹபுகளும் அவற்றின் இமாம்களும்
- மத்ரஸதுல் அஸர் vs மத்ரஸதுர் ரஃயு

> 📖 **அத்தியாய ஆரம்ப ஹதீஸ் (புஹாரி, முஸ்லிம்):** مَنْ يُرِدِ اللهُ بِهِ خَيْرًا يُفَقِّهْهُ فِي الدِّيْنِ
> "யாருக்கு அல்லாஹ் நலவை நாடுகிறானோ அவருக்கு **மார்க்கத்தில் தெளிவைக்** கொடுப்பான்."

---

## 1. பிக்ஹ் என்றால் என்ன? ⭐
- இஸ்லாமிய வரலாற்றில் தோன்றிய பல்வேறு அறிவியற் கலைகளுள் **பிக்ஹுக் கலை முதன்மையானது**; இஸ்லாமியக் கலைகளில் **இதுவே முதலில் தோன்றிய கலை.**
- **"பிக்ஹ்" (الفقه)** = **விளக்கம்.**
- ஷரீஅத்தில் **அல்குர்ஆன், ஸுன்னா, இஜ்திஹாத்** அடிப்படையில் பெறப்பட்ட சட்டங்கள் பிக்ஹில் உள்வாங்கப்பட்டுள்ளன.

---

## 2. பிக்ஹுக் கலையின் தோற்றமும் வளர்ச்சியும் ⭐

| காலம் | நிகழ்வு |
|---|---|
| **தாபிஈன்கள் காலம்** | பிக்ஹ் ஒரு **தனிக்கலையாக** வளர்ச்சியடைய ஆரம்பித்தது; இஸ்லாமிய தேசத்தின் பிரதான நகரங்களில் பிரபல முஜ்தஹித்களின் **பிக்ஹ் விளக்க வகுப்புக்கள்**; புதிய பிரச்சினைகளுக்கு இஜ்திஹாத் மூலம் தீர்ப்புகள் |
| **தபஉத் தாபிஈன்கள் காலம்** | பிக்ஹ் துறையின் **பொற்காலம்**; பல புதிய பிரச்சினைகளுக்குத் தீர்ப்புகள் → அவை திரட்டப்பட்டு **பிக்ஹ் சட்டத் தொகுப்புக்கள்** → **மத்ஹபுகள்** தோற்றம் |

- வரலாற்றில் பல மத்ஹபுகள் தோன்றினாலும் பல்வேறு காரணங்களால் **நான்கு மத்ஹபுகள் நிலைபெற்றன**; அவை தோற்றத்துக்குக் காரணமான **இமாம்களின் பெயர்களால்** அழைக்கப்படுகின்றன.
- இவர்களின் முயற்சி **முகல்லிதுகளாகிய பொதுமக்கள்** இஸ்லாத்தின் அடிப்படையில் வாழ்வதற்கு **இலகுவாக** அமைந்தது.

> 📌 **முகல்லித் (مقلّد)** = முஜ்தஹித்களின் தீர்ப்புகளைப் பின்பற்றும் பொதுமக்கள். **முஜ்தஹித்** = இஜ்திஹாத் செய்யும் தகுதியுள்ள அறிஞர்.

## 3. நான்கு இமாம்கள் ⭐

### (1) இமாம் அபூஹனீபா (ரஹ்) – ஹிஜ்ரி 80–150
| விடயம் | தகவல் |
|---|---|
| **இயற்பெயர்** | **நுஃமான் இப்னு ஸாபித்** |
| **பிறப்பிடம்** | **கூபா** |
| **சிறப்புப் பெயர்** | **இமாமுல் அஃழம்** |
| தொழில் | **வியாபாரி**; ஆனாலும் மார்க்கக் கலைகளைக் கற்பதில் ஆர்வம் |
| **ஆசிரியர்** | கூபாவின் பிரபல அறிஞர் **ஹம்மாத் பின் அபீசுலைம்**; ஹஜ் பயணங்களில் மக்கா, மதீனா அறிஞர்களிடமும் கற்றார்; ஹம்மாதின் வபாத்துக்குப் பின் அவ்வகுப்பைத் **தலைமையேற்று** நடத்தினார் |
| **நூல்** | தீர்வுகள் ஆவணப்படுத்தப்பட்டு **"பிக்ஹுல் அக்பர்"** என்ற பெயரில் வெளியாகியது |
| **சிந்தனைப் போக்கு** | அவர் காலத்தில் **ஹதீஸ்களின் நம்பகத்தன்மை தெளிவின்மையால்** தாம் சரியென இனங்கண்ட ஹதீஸ்களை ஆதாரமாகக் கொண்டு இஜ்திஹாத் மூலம் தீர்ப்பளித்தார் → **"மத்ரஸதுர் ரஃயு"** |
| **மாணவர்கள்** | **இமாம் அபூயூசுப், ஸுபர், ஹஸன் ஷைபானி** – ஆசிரியரின் கருத்துக்களை ஹதீஸ்களுடன் இணைத்து மெருகூட்டினர் |
| **மத்ஹப்** | **ஹனபி மத்ஹப்**; இமாம் அபூயூசுப் **கலீபா ஹாரூனின்** காலத்தில் **பிரதம நீதியரசராகப்** பணியாற்றியதால், **கலீபா ஹாரூன்** காலத்தில் **அரச மத்ஹபாகப்** பிரகடனம் |

### (2) இமாம் மாலிக் (ரஹ்) – ஹிஜ்ரி 93–179
| விடயம் | தகவல் |
|---|---|
| **இயற்பெயர்** | **மாலிக் இப்னு அனஸ்** |
| **பிறப்பிடம்** | **மதீனா** |
| **சிறப்புப் பெயர்** | **இமாமுல் மதீனா** |
| காலம் | இமாம் அபூஹனீபாவின் **சமகாலத்தவர்**; மதீனாவின் **தாபிஈ அறிஞர்களிடம்** ஹதீஸையும் பிக்ஹையும் கற்றார் |
| பாடபோதனை | மதீனாவில்; மாணவர்கள், பொதுமக்கள், சிலபோது **கலீபாக்களும்** கலந்துகொண்டனர் |
| **சிந்தனைப் போக்கு** | மதீனாவில் வாழ்ந்ததால் **ஹதீஸ்களைப் பெறுவது இலகு** → குர்ஆன், ஸுன்னாவின் அடிப்படையில் தீர்வு → **"மத்ரஸதுல் அஸர்"** |
| **நூல்** | **முவத்தா** |
| **மத்ஹப்** | **மாலிகி மத்ஹப்**; மாணவர் **யஹ்யா அந்தலூஸி** மூலம் **ஸ்பானியாவில்** அறிமுகம்; **கலீபா இரண்டாம் ஹகமின்** காலத்தில் அங்கு **அரச மத்ஹப்** |
| செல்வாக்கு | **வட, மேற்கு ஆபிரிக்க நாடுகளில்** குறிப்பிடத்தக்க செல்வாக்கு |

### (3) இமாம் ஷாபிஈ (ரஹ்) – ஹிஜ்ரி 150–204
| விடயம் | தகவல் |
|---|---|
| **இயற்பெயர்** | **முஹம்மத் இப்னு இத்ரீஸ்** |
| **பிறப்பிடம்** | **பலஸ்தீன் – காஸா** |
| வம்சம் | **குறைஷி** |
| **சிறப்புப் பெயர்** | **ஆலிமுல் குறைஷ்** |
| கல்வி | **மக்கா, மதீனா**; **பக்தாதில்** கற்பித்தல்; **யமனில்** அரச பணி; பக்தாதில் **முப்தியாகவும் போதகராகவும்**; **முஃதஸிலாக்களின் தலையீடு** அதிகரித்ததால் **எகிப்து** சென்றார் |
| திறமைகள் | ஸுன்னா, பிக்ஹுடன் **அறபு இலக்கியம், மருத்துவம்**; **கவிஞராகவும்** புகழ் |
| **நூல்கள்** | **முஸ்னத் இமாம் ஷாபிஈ, கிதாப் அல் உம்மு, அர்ரிஸாலது உஸூலிய்யா** |
| **ஆசிரியர்கள்** | **இமாம் மாலிக்**, ஹனபி மத்ஹபைச் சேர்ந்த **இமாம் அபூயூசுப்** |
| **சிந்தனைப் போக்கு** | **மத்ரஸதுல் அஸர், மத்ரஸதுர் ரஃயு ஆகிய இரண்டையும்** உள்வாங்கியதால் **முற்போக்குத் தன்மை** |
| **தீர்ப்புகள்** | **பக்தாதில்** வழங்கியவை = **கதீம் (பழையவை)**; **எகிப்தில்** வழங்கியவை = **ஜதீத் (புதியவை)** |
| **மத்ஹப்** | **ஷாபிஈ மத்ஹப்**; **சுல்தான் ஸலாஹுத்தீனின்** காலத்தில் **எகிப்தில் அரச மத்ஹப்** |
| பின்பற்றுவோர் | **இலங்கை, இந்தோனேஷியா, மலேசியா, எகிப்து** போன்ற நாடுகளில் பெரும்பாலானோர் |

### (4) இமாம் ஹன்பலி (அஹ்மத் இப்னு ஹன்பல்) (ரஹ்) – ஹிஜ்ரி 164–241
| விடயம் | தகவல் |
|---|---|
| **இயற்பெயர்** | **அஹ்மத் இப்னு முஹம்மத் ஹன்பல்** |
| **பிறப்பிடம்** | **பக்தாத்** (அங்கேயே வளர்ந்தார்) |
| **ஆசிரியர்கள்** | **இமாம் ஷாபிஈ, இமாம் அபூயூசுப்** |
| துறைகள் | **ஹதீஸ், பிக்ஹ்** இரண்டிலும் பங்களிப்பு |
| **நூல்** | **முஸ்னத் அஹ்மத்** |
| பின்னணி | **கிரேக்க சிந்தனையின் செல்வாக்கினால்** தோன்றிய **முஃதஸிலாக்களின்** கருத்துக்கள் பரவியிருந்த காலத்தில் குர்ஆன், ஸுன்னாவின் அடிப்படையில் சிந்தனைகளை முன்வைத்தார் |
| **சிந்தனைப் போக்கு** | **"மத்ரஸதுல் அஸர்"** |
| **மத்ஹப்** | **ஹன்பலி மத்ஹப்**; அப்பாஸியக் **கலீபா முதவக்கிலின்** காலத்தில் **அரச மத்ஹப்** |
| செல்வாக்கு | **சவூதி அரேபியாவில் அரச அங்கீகாரம்**; அரேபியத் தீபகற்பத்தில் செல்வாக்கு |

- இந்நால்வரைத் தவிர **வேறு பல அறிஞர்களும்** பிக்ஹுக்குப் பங்காற்றியுள்ளனர்; அவர்களின் கருத்துக்களும் சட்டப் பிரச்சினைகளுக்கான தீர்வுகளைத் தேடுவதில் கவனத்தில் கொள்ளப்படுகின்றன.

## 5. மத்ரஸதுல் அஸர் vs மத்ரஸதுர் ரஃயு ⭐

| | **மத்ரஸதுல் அஸர் (مدرسة الأثر)** | **மத்ரஸதுர் ரஃயு (مدرسة الرأي)** |
|---|---|---|
| அடிப்படை | **குர்ஆன், ஸுன்னா (ஹதீஸ்)** அடிப்படையில் தீர்வு | தாம் சரியென இனங்கண்ட ஹதீஸ்களுடன் **இஜ்திஹாத் / அபிப்பிராயம்** மூலம் தீர்வு |
| இமாம்கள் | **மாலிக், அஹ்மத்** | **அபூஹனீபா** |
| இணைத்தவர் | **ஷாபிஈ** – இரண்டையும் உள்வாங்கினார் |

### முஜ்தஹித் vs முகல்லித்
| முஜ்தஹித் | முகல்லித் |
|---|---|
| குர்ஆன், ஸுன்னாவிலிருந்து இஜ்திஹாத் மூலம் தீர்ப்புக் காண்பவர் | முஜ்தஹித்களின் தீர்ப்புகளைப் பின்பற்றும் பொதுமக்கள் |

## 6. முக்கிய அறபுச் சொற்கள்

## ✅ விரைவு மீட்டல்
- பிக்ஹ் = விளக்கம்; முதலில் தோன்றிய இஸ்லாமியக் கலை.
- தாபிஈன்கள் காலம் – தனிக்கலையாக வளர்ச்சி; தபஉத் தாபிஈன்கள் காலம் – பொற்காலம், மத்ஹபுகள் தோற்றம்.
- அபூஹனீபா: நுஃமான் இப்னு ஸாபித், கூபா, இமாமுல் அஃழம், ஹம்மாத், பிக்ஹுல் அக்பர், ரஃயு, ஹாரூன்.
- மாலிக்: மாலிக் இப்னு அனஸ், மதீனா, இமாமுல் மதீனா, முவத்தா, அஸர், யஹ்யா அந்தலூஸி – ஸ்பானியா – இரண்டாம் ஹகம்.
- ஷாபிஈ: முஹம்மத் இப்னு இத்ரீஸ், காஸா, ஆலிமுல் குறைஷ், அல் உம்மு, அர்ரிஸாலா, கதீம்/ஜதீத், ஸலாஹுத்தீன், இலங்கையில் பெரும்பான்மை.
- ஹன்பல்: அஹ்மத் இப்னு முஹம்மத் ஹன்பல், பக்தாத், முஸ்னத், அஸர், முதவக்கில், சவூதி.

# தரம் 11 – அத்தியாயம் 10: இஸ்லாத்தின் புனிதஸ்தலங்கள்

## 🎯 இந்த அத்தியாயத்தில் கற்பவை
- மூன்று புனிதஸ்தலங்களும் அவற்றின் ஆன்மீக அந்தஸ்தும்
- கஃபதுல்லாஹ் – வரலாறு
- அல் மஸ்ஜிதுல் அக்ஸா – வரலாறு
- மஸ்ஜிதுன் நபவி – வரலாறும் பங்களிப்பும்

> 📖 **அத்தியாய ஆரம்ப ஹதீஸ் (புஹாரி):** لَا تُشَدُّ الرِّحَالُ إِلَّا إِلَى ثَلَاثَةِ مَسَاجِدَ: مَسْجِدِيْ هٰذَا، وَالْمَسْجِدُ الْحَرَامُ، وَالْمَسْجِدُ الْأَقْصَى
> "**மூன்று புனிதஸ்தலங்களுக்கு மாத்திரமே** புனித யாத்திரை மேற்கொள்ள முடியும்: என்னுடைய இப்பள்ளி (மஸ்ஜிதுன் நபவி), மஸ்ஜிதுல் ஹராம், மஸ்ஜிதுல் அக்ஸா."

---

## 1. மூன்று புனிதஸ்தலங்கள் ⭐
- மஸ்ஜித்கள் இஸ்லாத்தின் புனிதஸ்தலங்கள்; அவற்றுள் **மூன்று மிக முக்கியமானவை:** **கஃபதுல்லாஹ் (மஸ்ஜிதுல் ஹராம்), மஸ்ஜிதுல் அக்ஸா, மஸ்ஜிதுன் நபவி.**
- இவை **முஸ்லிம் உம்மத்தின் உயிரோட்டத்துடன்** பின்னிப் பிணைந்தவை.
- யாத்திரைக்குரிய ஸ்தலங்களாக **இம்மூன்றை மட்டுமே** நபி ﷺ குறிப்பிட்டமை அவை ஏனைய மஸ்ஜித்களிலிருந்து முதன்மை பெறக் காரணம்.

### ஆன்மீக அந்தஸ்து (புஹாரி) ⭐
| மஸ்ஜித் | ஒரு தொழுகை = |
|---|---|
| **மஸ்ஜிதுல் ஹராம்** | **ஓர் இலட்சம் (1,00,000)** தொழுகைகள் |
| **மஸ்ஜிதுன் நபவி** | **ஆயிரம் (1,000)** தொழுகைகள் |
| **மஸ்ஜிதுல் அக்ஸா** | **ஐந்நூறு (500)** தொழுகைகள் |

## 2. கஃபதுல்லாஹ் (كعبة الله) ⭐
- இஸ்லாத்தில் **முதல் அந்தஸ்தைப்** பெற்ற இறை இல்லம்; உலகில் **முதன்முதலாக அமைக்கப்பட்ட** இறை இல்லமும் இதுவே.
> 📖 **(3:96):** மனிதர்களுக்காக அமைக்கப்பட்ட மஸ்ஜித்களில் முதன்மையானது நிச்சயமாக **பக்காவில் (மக்காவில்)** இருப்பதுதான்; அது மிக்க பாக்கியமுள்ளது; உலகத்தாருக்கு நேரான வழியை அறிவிக்கக்கூடியது.

### வரலாற்றுக் காலவரிசை
| காலம் | நிகழ்வு |
|---|---|
| ஆரம்பம் | முதன்முதலாக **ஆதம் (அலை)** கட்டினார்கள் (வரலாறு); அதற்கு முன் **மலக்குகள்** கட்டினர் என்ற பொதுவான நம்பிக்கையும் உண்டு |
| நூஹ் (அலை) காலம் | **வெள்ளத்தால் இடிந்து** மணல் திட்டுப் போல் உயர்ந்திருந்தது |
| இப்ராஹீம் (அலை) | அல்லாஹ்வின் கட்டளைப்படி மனைவி **ஹாஜரையும்** மகன் **இஸ்மாஈலையும்** பலஸ்தீனத்திலிருந்து அழைத்து வந்து தனியாக விட்டுச் சென்றார்கள் → அல்லாஹ் **ஸம்ஸம்** எனும் வற்றாத நீரூற்றை அருளினான் → மக்கள் குடியேறினர் |
| இப்ராஹீம் (அலை) – 4ஆவது வருகை | இப்ராஹீம் (அலை) **நான்கு முறை** மக்கா வந்தார்கள்; **நான்காவது** முறையே **தந்தையும் மகனும்** சேர்ந்து கஃபாவை மீண்டும் கட்டினர் |
| | மக்காவுக்காகவும் மக்களுக்காகவும் இப்ராஹீம் (அலை) பிரார்த்தித்தார்கள் **(2:126)** |
| | ஒரு **கட்டின் மேல் நின்று** சுவர்களை எழுப்பினார்கள்; அதில் பதிந்த **காற்பாதம் இன்றும்** காணக்கூடியது; அவ்விடத்தைத் தொழுமிடமாகக் கொள்ளுமாறு அல்லாஹ் கூறுகிறான் **(2:125)** – **மகாமு இப்ராஹீம்** |
| **கி.பி. 440** | இஸ்மாஈல் (அலை) வழித்தோன்றலான **அத்னானின்** பரம்பரையில் வந்த **குஸை** மக்காவைக் கைப்பற்றினார் → தலைமைத்துவம் **குறைஷியர்** கைக்கு |
| பின்னர் | ஹாஷிம் பரம்பரையில் வந்த **அப்துல் முத்தலிப்** – கஃபா நிருவாகம்; **ஜுர்ஹும்** கோத்திரத்தார் **முற்றாக மூடிவிட்டுச் சென்ற ஸம்ஸம் கிணற்றை** மீண்டும் கண்டுபிடித்தார்; அவர் காலத்திலேயே **ஆப்ரஹாவின் யானைப்படைச் சம்பவம்** |
| யானைச் சம்பவத்துக்கு **30 வருடங்களின் பின்** | கஃபா **புனர்நிர்மாணம்**; **ஹஜருல் அஸ்வத்தை** உரிய இடத்தில் வைப்பது யார் என்ற குறைஷியர் தகராறில், நடுவராக நியமிக்கப்பட்ட **நபி ﷺ அவர்களின் கரத்தால்** வைக்கப்பட்டது |
| ஹிஜ்ரத்தின் பின் | நபி ﷺ, ஸஹாபாக்கள் **மஸ்ஜிதுல் அக்ஸாவை** நோக்கித் தொழுதனர்; கஃபாவை நோக்கித் தொழ வேண்டும் என்பது நபியின் பேரவா → **கிப்லா மாற்றம் (2:144)** |
| **ஹிஜ்ரி 8** | **மக்கா வெற்றி** – நபி ﷺ அங்கு **ஏகத்துவத்தை** நிலைநிறுத்தினார்கள் |

👉 இப்ராஹீம் (அலை) காலம் முதல் **ஏகத்துவத்தின் சின்னம்**; இன்று **ஹஜ் கடமையின் தலம்**, **முஸ்லிம் உம்மத்தின் இதயம்.**

> 📖 **(2:144):** (நபியே!) உங்கள் முகம் அடிக்கடி வானத்தை நோக்குவதைக் காண்கிறோம்; நீங்கள் விரும்பும் கிப்லா(வாகிய மக்கா)வின் பக்கமே உங்களைத் திருப்புகிறோம்; **மஸ்ஜிதுல் ஹராமின் பக்கமே** முகத்தைத் திருப்புங்கள்.

## 3. அல் மஸ்ஜிதுல் அக்ஸா (المسجد الأقصى) ⭐
- **பலஸ்தீனத்தில்** உள்ள முஸ்லிம்களின் புனிதஸ்தலம்; வரலாறு கஃபாவைப் போன்றே பழமையானது.
- முதலில் **ஆதம் (அலை)** கட்டியது தூர்ந்துபோனது; பின்னர் **இப்ராஹீம் (அலை)** புனர்நிர்மாணம் செய்தார்கள் என்பது பெரும்பாலானோரின் கருத்து.

> 📖 **ஹதீஸ் (புஹாரி) – அபூதர் அல் கிபாரி (ரழி):** "பூமியில் முதலில் கட்டப்பட்ட பள்ளி எது?" – "**அல் மஸ்ஜிதுல் ஹராம்**". "பின்னர்?" – "**அல் மஸ்ஜிதுல் அக்ஸா**". "இடைப்பட்ட காலம்?" – "**நாற்பது வருடங்கள்**."

- அல்லாஹ் அக்ஸாவையும் சூழவுள்ள பிரதேசங்களையும் **புனித பூமியாக** ஆக்கினான்; வரலாற்றில் இவை **"ஷாம்"** தேசத்தினுள் அடங்குகின்றன.
- சிறப்புக்குக் காரணம்: **அதிகமான நபிமார்கள் வாழ்ந்து மரணித்த இடம்.**

### வரலாற்றுக் காலவரிசை
| காலம் | நிகழ்வு |
|---|---|
| இப்ராஹீம் (அலை) பின் | **இஸ்ஹாக் (அலை), யஃகூப் (அலை)** நிர்வகித்தனர் |
| யூஸுப் (அலை) காலம் | சகோதரர்களின் துரோகத்தின் விளைவாக யஃகூப் (அலை) குடும்பம் **எகிப்தில்** குடியேறியது → அக்ஸாவை **இழந்தனர்** |
| | **மூஸா (அலை)** முதல் பல நபிமார்கள் மீட்க முயன்றும் முடியவில்லை |
| | **தாவூத் (அலை)** மீட்டெடுத்தார்; **சுலைமான் (அலை)** சிறப்பாக **மீளக்கட்டி விசாலப்படுத்தினார்** |
| | பின் **ஈஸா (அலை)** வரும் வரை பல நபிமார்கள் போதனை |
| **கி.பி. 621** | **மிஃராஜ்** – முதற்கட்டம் மக்காவிலிருந்து அக்ஸாவுக்கு; அங்கு முன்னைய **நபிமார்களுக்குத் தலைமை தாங்கித் தொழுகை** நடத்தினார்கள்; பின் **ஸித்ரதுல் முன்தஹாவில்** அல்லாஹ்வுடனான சந்திப்பு; **தொழுகை** பரிசாகப் பெற்றார்கள்; அக்ஸாவே **(முதல்) கிப்லா** |
| | மஸ்ஜிதுல் ஹராமிலிருந்து அக்ஸாவுக்குச் சென்ற பயணம் = **இஸ்ரா**; ஸூறதுல் இஸ்ரா (பனூ இஸ்ராயீல்) முதல் வசனம் குறிப்பிடுகிறது. சில அறிஞர்கள்: நபிமார்களின் பூமியான பலஸ்தீன் இனி முஹம்மத் ﷺ க்குச் சொந்தம் என உறுதிப்படுத்தவே இஸ்ரா நிகழ்ந்தது |
| **கி.பி. 632** | நபி ﷺ வபாத்; ரோமர், பாரசீகர் அச்சுறுத்தல்; அபூபக்கர் (ரழி) அனுப்பிய படைகள் உமர் (ரழி) காலத்தில் வெற்றிகள் |
| **கி.பி. 636 (ஹி. 15)** | **பலஸ்தீன வெற்றி**; குத்ஸ் நகரைப் பொறுப்பேற்க **உமர் (ரழி)** அழைக்கப்பட்டார்; கிறிஸ்தவர்களுடன் ஒப்பந்தம் – இன்றும் **"உமர் சாசனம்"** |
| | உமர் (ரழி) அசுத்தமான இடத்தைத் **தம் கைகளாலேயே** சுத்தம் செய்து **இரு ரக்அத்** தொழுதார்கள் – நபிக்குப் பின் அங்கு தொழுத **முதல் மனிதர்**; அதான் கூறிய முதல் மனிதர் **பிலால் (ரழி)**; **மூவாயிரம் பேர்** தொழக்கூடிய அளவு கட்டப்பட்டது |
| **கி.பி. 1088–1290** | **சிலுவைப் போர்கள்**; மீட்ட தலைவர்கள் – **ஸலாஹுத்தீன் ஐயூபி, மஹ்மூத் அல் குதுஸ்** (எகிப்தை ஆண்டவர்கள்) |
| **1924** | இஸ்லாமிய **கிலாபத் வீழ்ச்சி**; அரபு நாடுகள் துண்டாடப்பட்டன |
| **1948** | பலஸ்தீனத்தில் **இஸ்ரேல்** உருவாக்கப்பட்டது |
| **1967** | இஸ்ரவேலர் அக்ஸாவுக்குத் **தீ வைத்தனர்**; **சுல்தான் நூருத்தீன் ஸன்கியின்** வரலாற்றுச் சிறப்புமிக்க **மின்பர்** தீக்கிரையானது |

> 📌 பாடநூலின்படி: மறுமை நாளின் முக்கிய அடையாளங்களுள் ஒன்றான முஸ்லிம்களுக்கும் **தஜ்ஜாலுக்கும்** இடையிலான யுத்தம் – **ஈஸா (அலை)** இறங்கி தஜ்ஜாலைக் கொல்வார்கள் – அக்ஸா அமைந்துள்ள **புனித பூமியிலேயே** நிகழும்.

## 4. மஸ்ஜிதுன் நபவி (المسجد النبوي) ⭐
- இஸ்லாத்தில் **இரண்டாவது** ஆன்மீக அந்தஸ்து.
- வரலாறு நபி ﷺ அவர்களின் **ஹிஜ்ரத்தைத் தொடர்ந்தே** ஆரம்பம்.
- **கி.பி. 622 செப்டம்பர் 27** இல் மதீனாவை அடைந்த நபி ﷺ, **அபூ ஐயூப் (அல் அன்ஸாரி) (ரழி)** வீட்டில் இருந்துகொண்டு கட்டிட வேலைகளை ஆரம்பித்தார்கள்.

### கட்டப்பட்ட விதம்
- நபி ﷺ அவர்களின் **ஒட்டகம் முதன்முதலாக மண்டியிட்ட இடம்** தெரிவு செய்யப்பட்டது; அது **இரு அநாதைகளுக்குச்** சொந்தமானது; **விலைக்கு** வாங்கப்பட்டது.
- நபி ﷺ **தோழர்களுடன் சேர்ந்து தானும் கடுமையாக உழைத்தார்கள்.**
- வாயிலின் இரு ஓரங்கள் **கற்களால்**; சுவர்கள் **கல்லாலும் மண்ணாலும்**; **பேரீச்ச மரத்தால் தூண்கள்**; அதன் **கீற்றுகளால் முகடுகள்.**
- ஆரம்பத்தில் **35 மீ. நீளம், 30 மீ. அகலம், மூன்று வாயில்கள்.**
- ஒருபுறத்தில் நபியின் **மனைவிமார்களுக்கான அறைகள்**; நபி ﷺ அபூ ஐயூப் வீட்டிலிருந்து அவற்றில் குடியேறினார்கள்.
- **வீடுவாசலற்ற ஏழைத் தோழர்களுக்காக** ஒரு பகுதி → **அஸ்ஹாபுஸ் ஸுப்பா (திண்ணைத் தோழர்கள்).**

> 📖 **(9:108):** ஆரம்ப தினத்திலேயே (அல்லாஹ்வின்) பயத்தின் மீது அமைக்கப்பட்ட மஸ்ஜிதே நீங்கள் நின்று தொழத் தகுதியுடையது; அதிலுள்ள மனிதர்கள் பரிசுத்தவான்களாக இருப்பதை விரும்புகின்றனர்; அல்லாஹ் பரிசுத்தவான்களையே நேசிக்கிறான்.

### நபி ﷺ காலத்தில் மஸ்ஜிதுன் நபவியின் பங்களிப்பு ⭐
தொழுகைக்கான இடம் மட்டுமல்ல:
- **பாடசாலை** (கல்வி)
- **நீதி மன்றம்** (பிரச்சினைகளுக்குத் தீர்ப்பு)
- **பாராளுமன்றம்** (நாட்டு விவகார மந்திராலோசனை)
- **களஞ்சியம்** (ஸக்காத், வரிகள் சேமித்து விநியோகம்)
- **இராணுவ முகாம்** (திட்டமிடல், பயிற்சி)
- **வரவேற்புக் கூடம்** (விருந்தினர், தூதுவர்கள்)

### விரிவாக்கம்
- **கைபர் யுத்தத்தைத்** தொடர்ந்து: நீளத்தில் **15 மீ.**, அகலத்தில் **20 மீ.** சேர்க்கப்பட்டு **2500 சதுர மீட்டர்.**
- பின்னர் **உமர், உஸ்மான் (ரழி)**, **உமையா, அப்பாஸிய, மம்லூக்கிய, உஸ்மானிய** ஆட்சியாளர்கள், இறுதியாக **ஸஊதி மன்னர் பஹத் பின் அப்துல் அஸீஸ்** விரிவுபடுத்தினர் → இன்று **உலகின் மிகப் பெரிய பள்ளிவாசல்களில்** ஒன்று.

## 5. முக்கிய அறபுச் சொற்கள்
| அறபு | பொருள் |
|---|---|
| كعبة الله | கஃபதுல்லாஹ் – அல்லாஹ்வின் இல்லம் |
| أصحاب الصفة | திண்ணைத் தோழர்கள் |
| الإسراء | மக்கா → அக்ஸா இரவுப் பயணம் |
| المعراج | விண்ணேற்றம் |
| سدرة المنتهى | ஏழாம் வானிலுள்ள எல்லை மரம் – அல்லாஹ்வுடனான சந்திப்பு நிகழ்ந்த இடம் |
| القضاعة / الجرهم | மக்காவில் வாழ்ந்த அரபுக் கோத்திரங்கள் (ஜுர்ஹும் – ஸம்ஸமை மூடிச் சென்றவர்கள்) |
| الهبل | ஹுபல் – கஃபாவில் இருந்த பிரதான சிலை |
| صلاح الدين | ஸலாஹுத்தீன் ஐயூபி |
| محمود القطز | மஹ்மூத் அல் குதுஸ் |
| نور الدين الزنكي | நூருத்தீன் ஸன்கி |

> ⚠️ "குழாஆ", "ஹுபல்" ஆகிய சொற்கள் பாடநூல் சொற்பட்டியலில் மட்டுமே உள்ளன; பாடத்தில் விளக்கம் இல்லை.

## ✅ விரைவு மீட்டல்
- 3 புனிதஸ்தலங்கள்: மஸ்ஜிதுல் ஹராம் (1,00,000), மஸ்ஜிதுன் நபவி (1,000), மஸ்ஜிதுல் அக்ஸா (500) – புஹாரி.
- கஃபா: 3:96 (முதல் இல்லம், பக்கா); ஆதம் → நூஹ் வெள்ளம் → இப்ராஹீம், இஸ்மாஈல் (4ஆவது வருகை); 2:125, 2:126; கி.பி. 440 குஸை; அப்துல் முத்தலிப் – ஸம்ஸம்; யானைச் சம்பவம் +30 வருடம் – ஹஜருல் அஸ்வத் நபியின் கரத்தால்; 2:144 கிப்லா; ஹி. 8 மக்கா வெற்றி.
- அக்ஸா: ஹராமுக்கு 40 வருடம் பின் (புஹாரி); தாவூத் மீட்பு, சுலைமான் விசாலிப்பு; கி.பி. 621 இஸ்ரா–மிஃராஜ்; கி.பி. 636 (ஹி. 15) உமர் – உமர் சாசனம்; முதல் அதான் – பிலால்; சிலுவைப் போர் 1088–1290 – ஸலாஹுத்தீன், மஹ்மூத் அல் குதுஸ்; 1924, 1948, 1967.
- நபவி: கி.பி. 622 செப். 27; அபூ ஐயூப் வீடு; இரு அநாதைகளின் நிலம்; 35×30 மீ., 3 வாயில்; அஸ்ஹாபுஸ் ஸுப்பா; 9:108; கைபருக்குப் பின் 2500 ச.மீ.; மன்னர் பஹத்.
